# Workout Sync companion

Requires XcodeGen and Xcode with iOS 18 or newer SDK. Generate the project with `xcodegen generate --spec ios/project.yml`, open `ios/WorkoutSync.xcodeproj`, select your Apple development team and a unique bundle identifier, then install on the paired iPhone. Named steps require iOS 18/watchOS 11 or later. Pairing, authorization, supported activities, and Watch delivery require a physical-device check. The simulator build alone cannot establish those behaviors.

Use Files to import a version-1 plan documented in `planner/README.md`; inspect each session and Workout preview, then explicitly schedule. Workouts are scheduled by date. The app lists scheduled workouts on matching dates but does not remove them. Changed sessions need distinct IDs, so removing an old version is a separate manual action. Scheduling provides no per-call error result; the app checks the scheduler afterward and reports how many requested IDs/dates were found. It cannot guarantee Watch delivery. Single-goal golf cannot encode a multi-step downshift; complete the downshift separately. Unsupported activity/goal/alert combinations are rejected, not silently changed.

This is an initial import/sync scaffold. The command-line validator checks structure and a minimum custom cooldown, not all protocol constraints. It does not yet calculate spacing, weekly zone allocation, strength pairings, golf load, recovery, or periodization; those require the planning workflow and review. It does not read HealthKit data. Do not describe the system as a fully automated or clinically validated planner.
